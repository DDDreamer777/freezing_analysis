主要功能脚本：

1、pause_analysis.py：停滞分析系统的主要实现，拥有参数计算、停滞分析、可视化等功能，直接运行会启用人为构造的测试数据（模拟两次停滞）

2、load_csv_analysis.py：导入轨迹追踪结果的接口，用于调用pause_analysis主实现，输入检测追踪的三维骨架结果csv文件（选用4-result文件夹下的zebrafish_tracks_3d.csv文件，放到根目录的input文件夹下），输出每个ID的停滞分析结果（放到根目录的output文件夹下，每个ID独享一个自己的文件）

3、config_threshold.py：自动生成停滞分析阈值的脚本，用于更新config中配置的阈值，输入检测追踪的三维骨架结果csv文件（input文件夹下的zebrafish_tracks_3d.csv文件），输出每个ID自定义阈值的json文件（自动放入input文件夹下）

4、pause_visualization.py：对特定ID的分析结果进行可视化的脚本，用输入为特定ID的停滞检测文件夹下的内容（load_csv_analysis的运行结果），输出为图片（output/output_picture文件夹下）

近期修改：

- 停滞空间从原有内容修改为：直接取时间窗口内所有点质心，并与窗口内所有运动点分别计算距离，如果这个距离在空间半径阈值内，就代表只在一个小空间内活动
- 原有分类逻辑较为简单，改进分类规则如下：速度慢+距离小+曲率小=停滞，速度慢+距离大+曲率小=滑行，速度慢+距离小+曲率大=原地扭动，速度慢+距离大+曲率大=扭动滑行；其余情况=混合因素
- 停滞速度在内的阈值设置很重要，目前绘制的图像来看基本是没有停滞，从Zef-3D的04数据集看也是这样，应该经过调研来修改阈值或者是人为结合原数据集进行判断
- 曲率计算的结果本来有点问题，现已修正，但是从曲率计算结果来看鱼的身体摆动幅度真的不大，也有可能是计算错误
- 在绘制停滞持续时间分布图时，人为将检测时间划分成了15个区间，因为停滞事件的次数太少，这会导致一个区间最多只有一个事件，甚至没有事件。如果你想切分的细一点，可以保留区间划分，如果你只想看大体，可以减少划分区间数
- 参考真实情境对运动距离的比例进行了修正：原先是直接将输入csv文件的数据单位当做毫米使用，但会导致离谱的输出，现引入pixel_to_mm参量能够调整实际比例尺
